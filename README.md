# Museo de la Música de Puerto Rico

Landing pública oficial del Museo de la Música de Puerto Rico. Es un sitio estático, sin base de datos, autenticación ni panel administrativo.

## Desarrollo local

Puede servirse con cualquier servidor HTTP estático. Por ejemplo:

```powershell
npx serve .
```

## Cloudflare Pages

- Framework preset: `None`
- Build command: vacío
- Build output directory: `/`
- Rama de producción: `main`

## Dominios

El dominio canónico es `https://museodelamusicadepr.com/`. Los dominios alternos deben redirigir permanentemente hacia esa URL. No se deben cambiar registros de correo ni nameservers sin inventariar y aprobar previamente el DNS.
